# Screenshots

Screenshots of the From The Farm Android app, taken on an Android emulator (API level 37) from the `kyra-localisation-p3` build.

**They show sample data.** The screens, layout and text are the real app, but the content (the crop "Tomatoes", quantities, dates, distances and match scores) is sample data used for testing, not records from the live service or real users. Google sign-in was not used.

Each image is 1137 × 2274 pixels. The app's own area is 1080 pixels wide; a thin strip of the screen's edge colour was added at each side so the image is at most 2:1, which is the limit for Play Store screenshots. There is no status bar or device frame.
